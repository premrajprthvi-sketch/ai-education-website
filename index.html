MODULE 01

What is Artificial Intelligence?

Artificial Intelligence (AI) refers to the simulation of human intelligence in machines that are programmed to think, reason, and learn like human beings.

Reasoning Automation Problem Solving

• Narrow AI (Weak AI): Designed for a specific task (e.g., chess engine, facial recognition).

• General AI (Strong AI): Theoretical machine possessing human-level cognitive capabilities across any problem domain.

• Goal: Rational decision-making, pattern comprehension, and automated problem-solving.

Focus: Cognitive Mimicry & Reasoning
MODULE 02

What is Machine Learning?

Machine Learning (ML) is a subfield of AI that enables systems to automatically learn and improve from experience and data without explicit programming.

Algorithms Training Data Pattern Matching

• Supervised Learning: Learning from labeled data (Input ➔ Target Output).

• Unsupervised Learning: Discovering hidden patterns in unlabeled data (Clustering).

• Reinforcement Learning: Agent learning through trial, error, rewards, and penalties.

Focus: Data-Driven Optimization
MODULE 03

Real-World AI Applications

AI transforms industries daily, from autonomous navigation to modern generative AI tools and medical breakthroughs.

Healthcare Autonomous Cars Generative AI

• NLP & LLMs: ChatGPT, translation services, text summarization.

• Healthcare: Early cancer detection in MRI and X-ray analysis.

• Autonomous Systems: Self-driving cars, robotics, supply chain optimization.

Focus: Practical Real-World Impact
